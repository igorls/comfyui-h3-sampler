How Frequency-Split Spectral Re-Noising Works

Plain Euler keeps pose and identity steady but leaves fine skin static. Full-band mid-step re-noising refreshes every spatial frequency at once—smoothing pores and mutating hands or clothing. Splitting noise in the 2D Fourier (FFT) domain locks large structure while refreshing fine texture, with zero extra model calls.

Active preset: Spectral 6 (default) 6 calls · Steps 0–1 Euler · Steps 2–4 FFT · Step 5 Euler
Low frequencies (r ≤ cutoff)
Locked deterministically to Euler. Protects pose, facial proportions, bare hands, props and printed text.
High frequencies (r > cutoff)
Variance-preserving fresh noise draws organic pores, stray hairs and fabric weave without altering noise scale (exact Gaussian marginal).
Emix(f) = √(1 − η(f)²)·Eold + η(f)·Enew Marginal: exact N(0, I) · 15% low-freq locked

Native Empty Picture fixes crusty text-to-image

Without a picture in its conditioning, H3 Image falls into an over-sharpened text-only mode with dark halos around hair and foliage. H3 Realism Empty Picture prepends a black 512 px picture's vision tokens on the first steps—no reference latent or checkpoint-specific calibration file needed. Because switching modes naturally shifts composition for the same seed, these comparisons are shown honestly side-by-side.

Measured Benchmarks

Measured on an RTX PRO 6000 Blackwell (96 GB), ComfyUI 0.45.6, minimax_h3_image_pruned_int8_convrot, identical prompts and seeds at 16 MP.

Photo Edits: Wire H3RealismKSampler on spectral 6 — fastest, highest facial likeness, locks hands, pores and woven fabric.
Text-to-Image: Add H3RealismEmptyPicture (end = 0.25) + spectral + texture 8 — eliminates text-only halos with crisp hair and skin.
InsightFace ID: Higher means closer to the reference face—but aggressive smoothing can artificially inflate cosine similarity while erasing pores (always inspect 1:1).
Laplacian RMS: Edge-sharpness sweet spot. Natural 16 MP skin sits around 5–9; values above 13 indicate crusty sharpening halos, while low drops signal plastic smoothing.
hf/mid ratio: High-to-mid spatial frequency energy ratio. Lower values on T2I (0.06–0.09 vs 0.16–0.21) confirm elimination of harsh fine stipple and crunchy needles.
Rank-1 steering: Single-vector activation shift tested as a calibration-based alternative to native Empty Picture mode switching.

Resolution Ceiling Test: How Big Can H3 Image Go?

Swept from 4 MP to 179 MP (10912×16384) on a 96 GB RTX PRO 6000. Memory was never the bottleneck (55 GB peak at 179 MP, no tiled decode). Quality holds cleanly to 96 MP; from 128 MP upward, H3's rotary position scaling (area-normalized RoPE) compresses neighbor spacing below 0.10 and fine textures break into 32 px token blocks across both int8 and bf16 checkpoints.

16 – 64 MP (Practical) 28 s – 2.2 min · Single hairs, pores, fabric weave
96 MP (Ceiling) 4.1 min · Verified clean limit (47 GB)

Install & Quick Start

  1. Clone into ComfyUI/custom_nodes

    Requires ComfyUI ≥ 0.45.0 (V3 node API + MiniMax H3 Image support). If nodes fail to appear after restart, update ComfyUI first. No extra pip packages required.

    cd ComfyUI/custom_nodes && git clone https://github.com/igorls/comfyui-h3-sampler

  2. Load the v2.0 template workflows

    Restart ComfyUI and open the template browser under H3 Realism Sampler, or download the packaged edit and text-to-image zips from CivitAI. Every loader includes official Comfy-Org model download metadata.

  3. Run the CPU test suite (optional)

    Verifies 2D FFT white-noise invariance, Euler parity, distilled head routing, second-pass tail alignment, V3 schemas and unique node IDs without a GPU.

    COMFYUI_PATH=/path/to/ComfyUI python tests/test_h3_realism.py

Upgrading from v1.x

Breaking change in v2.0: Running git pull replaces H3Image* nodes with H3Realism* nodes. Existing v1.x graphs will show missing nodes until you re-import the v2.0 workflows from example_workflows/ or CivitAI.

To publish cleanly on the ComfyUI Registry and avoid generic node ID clashes with other MiniMax H3 custom node packs, v2.0 uses the uniform H3Realism* prefix:

  • H3ImageKSampler → H3RealismKSampler
  • H3ImageSampler → H3RealismSampler
  • H3ImageSigmas → H3RealismSigmas
  • H3ImageEmptyPicture → H3RealismEmptyPicture
  • New: H3RealismResolutionSelector (up to 96 MP+ with live preview)
cd ComfyUI/custom_nodes/comfyui-h3-sampler && git pull

Restart ComfyUI and load the updated v2.0 template workflows.
